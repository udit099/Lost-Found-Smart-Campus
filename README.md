🚀 **Project Showcase: Smart Campus Lost & Found System**

I'm excited to share our team project, **Smart Campus Lost & Found System**, developed by **Team Code Collective (C²)**! 🎓💻

🔍 **About the Project**

The Smart Campus Lost & Found System is a full-stack web application designed to help students report lost belongings, post found items, search existing reports, and identify potential matches. Our goal is to make recovering lost items on campus easier, faster, and more organized.

🛠️ **Tech Stack**
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API:** REST API
- **Authentication:** Spring Security & JWT
- **ORM:** Spring Data JPA & Hibernate

✨ **Key Features**
- 👤 Student registration and login
- 📦 Lost and found item reporting
- 🔎 Search and view item reports
- 🔗 Potential lost-and-found matching
- ✅ Item return tracking
- 🛡️ Admin dashboard and report management

📚 **What We're Learning**
Through this project, we're gaining practical experience in full-stack development, REST API integration, database management, authentication, and collaborative software development.
